# 暖阳爬虫 — 腾讯云函数部署指南

## 原理

爬虫部署在腾讯云函数(SCF)上，由腾讯国内服务器直接访问B站API，不经过你的路由器和电脑。每天6:00和15:00自动运行，爬完通过GitHub API更新数据，GitHub Pages自动部署网站。

## 前提条件

- 腾讯云账号（注册免费，需实名认证）
- GitHub Token（已有，`ghp_` 开头那个）

## 部署步骤

### 第1步：上传代码包

1. 打开 https://console.cloud.tencent.com/scf
2. 点击「新建」→「从头开始」
3. 配置：
   - 函数名称：`nuanyang-crawler`
   - 运行环境：`Python 3.9`（或3.10/3.12）
   - 执行方法：`index.main_handler`
   - 内存：`256MB`
   - 执行超时：`900`（15分钟，爬虫需要几分钟）
4. 上传代码：
   - 点击「本地上传zip」
   - 选择 `nuanyang-scf.zip` 文件
5. 点击「完成」

### 第2步：配置环境变量

在函数详情页 →「函数管理」→「函数配置」→「环境变量」中添加：

| Key | Value |
|-----|-------|
| `GITHUB_TOKEN` | `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` |
| `GITHUB_OWNER` | `PeaCocoa` |
| `GITHUB_REPO` | `nuanyang` |

### 第3步：配置定时触发器

在函数详情页 →「触发管理」→「创建触发器」：

**触发器1（早上6点）：**
- 触发方式：定时触发
- 触发周期：自定义
- Cron表达式：`0 0 6 * * *`
- 备注：每日6点爬虫

**触发器2（下午15点）：**
- 触发方式：定时触发
- 触发周期：自定义
- Cron表达式：`0 0 15 * * *`
- 备注：每日15点爬虫

### 第4步：测试

在函数详情页点击「立即运行」测试一次，查看日志确认：
- B站API能正常返回
- GitHub文件更新成功
- 访问 https://peacocoa.github.io 确认视频数据已更新

## 验证

部署完成后：
- 每天 6:00 和 15:00 自动爬取
- 每月 19 日自动跳过
- 数据自动推送到 GitHub
- 网站自动更新
- 你的电脑和路由器完全不用开

## 更新UP主列表

如需修改UP主列表，重新打包上传：
1. 修改 `data/upmasters.json`
2. 复制到 `scf/` 目录
3. 重新打包 zip 上传到腾讯云函数
